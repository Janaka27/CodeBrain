1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
CodeBrain (AI Code Reviewer) is a full-stack web application engineered to provide real-time, interactive AI assistance and automated code auditing. The system is designed to analyze raw source code, technical documentation, architectural queries, and system stress points under high-concurrency environments.

2. BACKEND & LARAVEL AI SDK INTEGRATION
--------------------------------------------------------------------------------
The backend is built on PHP 8.4 and Laravel 13, leveraging the official `laravel/ai` SDK (v0.11.2) to orchestrate agent-driven workflows with Google Gemini 3.6 Flash.

Key Backend Components:
• AI Agents (`app/Ai/Agents/`):
  - `ChatAgent`: Configured with system instructions for multimodal response formatting, conversational engagement, and dynamic file handling. Uses `#[Model('gemini-3.6-flash')]` and `#[MaxSteps(5)]`.
  - `ReviewAgent`: Specialized agent for identifying logical bugs, performance bottlenecks, security flaws, and design pattern improvements.
  - Interfaces Implemented: `Laravel\Ai\Contracts\Agent`, `Conversational`, `HasTools`.
  - Conversation Memory: Employs the `Laravel\Ai\Concerns\RemembersConversations` trait to maintain state across user sessions.

• Function Calling / Custom Tools (`app/Ai/Tools/`):
  - `GetCurrentDateTime`: Provides date, time, and timezone context dynamically via `Laravel\Ai\Contracts\Tool` and `JsonSchema`.
  - `GetCurrentWeather`: Fetches live weather metrics using Open-Meteo Geocoding & Forecast APIs through Laravel's `Http` facade.

• Multimodal File Processing (`app/Http/Controllers/ChatController.php`):
  - Automatically identifies file MIME types and wraps incoming uploads into Laravel AI file abstractions:
    * `StoredImage` for image assets (JPG, PNG, WebP)
    * `StoredDocument` for documents & scripts (PDF, DOCX, TXT, ZIP, Code)
    * `StoredAudio` & `StoredVideo` for media files

• Response Streaming & Resiliency:
  - Streams LLM responses to the client using `Symfony\Component\HttpFoundation\StreamedResponse` formatted as Server-Sent Events (`text/event-stream`).
  - Implements explicit exception trapping for `Laravel\Ai\Exceptions\RateLimitedException` to notify clients smoothly when provider limits are reached.

• Persistence Layer (`database/migrations/`):
  - Uses `Laravel\Ai\Migrations\AiMigration` to provision `agent_conversations` and `agent_conversation_messages` tables, supporting participant tracking, attachment metadata JSON serialization, tool call logging, and message history.

• Typed API Contracts:
  - Uses Laravel Wayfinder (`laravel/wayfinder`) to generate type-safe TypeScript helper functions for controllers and routes.


3. FRONTEND UI & UX ENGINEERING
--------------------------------------------------------------------------------
The client dashboard is developed using React 19, Inertia.js v3, and Tailwind CSS v4, adhering to modern design principles with high visual impact.

Key Frontend Components & Libraries:
• Single Page Application Framework:
  - `Inertia.js v3` (`@inertiajs/react` & `@inertiajs/vite`) provides seamless client-side SPA navigation without API boilerplate.

• Styling & Design System:
  - `Tailwind CSS v4` (`@tailwindcss/vite`) configured with glassmorphism, HSL tailwind color palettes, and custom animations (`tw-animate-css`).
  - Utilizes `class-variance-authority` (cva), `clsx`, and `tailwind-merge` for predictable component styling.

• Headless UI & Icons:
  - `Radix UI` primitives (`@radix-ui/react-dialog`, `@radix-ui/react-dropdown-menu`, `@radix-ui/react-tooltip`, `@radix-ui/react-select`, `@radix-ui/react-collapsible`, etc.) ensure accessibility (a11y) and keyboard navigation.
  - `Lucide React` icons (`lucide-react`) for intuitive visual indicators across navigation, file attachment tags, audit badges, and message roles.

• Markdown & Code Highlighting Pipeline:
  - `Marked` (`marked` v18): Parses incoming streaming AI markdown content in real-time.
  - `DOMPurify` (`dompurify` v3): Sanitizes HTML output to safeguard against malicious script injections.
  - `Highlight.js` (`highlight.js` v11): Formats code snippets with language detection, custom header banners, and interactive single-click "Copy Code" clipboard triggers.

• Key UI/UX Features Implemented in `chat.tsx`:
  - **Code Failover & Vulnerability Mode**: Dedicated view with customized audit prompts and category breakdown cards (Security, Traffic Bottlenecks, Exceptions, Resilience).
  - **Multimodal Attachment Dock**: File upload preview bar supporting images, PDF, Word, Excel, and code files with clear indicators.
  - **Image Lightbox Modal**: Click-to-expand lightbox overlay for inspecting uploaded images.
  - **Graceful Deletion with Undo Toast**: Features a 3-second grace period with a CSS progress bar animation allowing users to undo chat deletions before permanent database purging.
  - **Context-Aware Streaming**: Live SSE stream consumption updates assistant message buffers dynamically.
